## 本轮修复与核验

CI 上传配置此前引用 `.build/dev-dmg/output/verification-report.txt`，但实际 verifier 将报告写入 `.build/dev-dmg/verification/`；上传会缺少这份报告。本轮修正路径，并加入 smoke.log 与 journeys/。现有 `if-no-files-found: error` 并不能保证每个 glob 都命中，因此该修复不能用其他文件已上传来替代。

本机核对上传路径确有对应 verifier 产物，并通过 YAML 语法检查；没有实际运行 GitHub Actions，不能声称上传/下载已验证。普通 push 仍只产生开发 artifacts，不创建 tag 或 Release。

执行入口：

```sh
bash scripts/check-upstream-pin.sh
FSEARCH_DEV_RUST_VERSION=1.99.0 bash scripts/package-dev-dmg.sh
bash scripts/verify-dev-dmg.sh --dmg .build/dev-dmg/output/Fsearch-Desktop-0.1.0-dev-9bda219060e7-universal.dmg
bash scripts/dev.sh check
bash scripts/dev.sh test
```

Rust check、Swift 构建与完整 XCTest 68 项 0 失败；本轮实际 DMG verifier 最终退出 0，安装报告为 PASSED。YAML 解析、路径核对和 diff whitespace 检查通过。本轮未增加测试接缝、框架或镜像测试。
