# T33：v0.2 文本旅程与边界验收

对应 [GitHub #47](https://github.com/wynnok/fsearch-desktop/issues/47)。真实证据来自固定上游 `0.2.1 / 88e63fdf850cf7749deae8198b187accd21f8ba5`。

## 验收旅程

- 服务层真实 Engine：`ContentSearchTests` → `FsearchEngineCheck content`，覆盖普通/正则、智能/区分/不区分大小写、范围与属性筛选、中文/emoji、CRLF、组合形态、非法正则恢复、无匹配、文件更新和 cursor 续查。
- 原生窗口：`bash scripts/content-validation.sh` 启动受控真实 Engine，验证内容入口、匹配行、Unicode 高亮、literal/regex/大小写、范围+筛选、续查、打开、Quick Look、无匹配与关闭。截图保留在 `.build/content-evidence/native/content-results.png`。
- 语义：文件数与内容匹配数分开；`complete`、`next`、`indexed` 与预算共同决定“可继续/停止/完成”，不把内容 cursor 当名称 offset。
- 脱敏：原生 smoke 导出的 `diagnostics.json` 不含匹配片段；默认诊断、偏好和查询历史仍不写入正文。

## 指南与回归

- 用户指南说明上游准入文本、大小/忽略规则、直接读取回退、候选/大小限制和云端未下载缺失；Quick Look 能预览 PDF/Office 不代表正文可检索。
- 名称搜索测试、既有原生名称旅程和内容文件动作在同一提交上回归通过；没有加入 PDF/Office/OCR、压缩包正文、保存查询、历史或符号/Git 等未确认 beta 扩展。

## 验证命令与限制

```sh
bash scripts/dev.sh check
bash scripts/dev.sh test --filter ContentSearchTests
bash scripts/dev.sh test --filter ContentSearchOptionsTests
bash scripts/dev.sh test --filter ContentPaginationTests
bash scripts/content-validation.sh
```

真实 Engine 测试必须在无额外 Seatbelt 限制的进程外运行；外层执行沙箱拒绝 `sandbox_init` 不是功能失败。T33 不替代 Intel/macOS 13、真实 TCC、个人磁盘默认集成、alpha 或正式发行验收，也不关闭父 Spec。
