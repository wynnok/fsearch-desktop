# T19：本地设置与进程内查询状态

对应 [GitHub #33](https://github.com/wynnok/fsearch-desktop/issues/33)，父规格 [SPEC-08](../specs/08-data-updates.md)。本次延续 `93f37fb` 的实现，不增加查询历史或保存查询功能。

## 实现与边界

- 本地设置只保存名称模式、显式排序、隐藏项、检查器可见性及权限引导跳过状态。查询、所选路径、搜索范围、属性筛选和错误不进入偏好文件。
- 检查器变化同步保存发布的新值，修复异步任务尚未执行就退出时偏好丢失的问题。回归先观察到失败，再修复为通过。
- 关窗只隐藏既有窗口，运行中的输入和选择留在同一个搜索模型中；新模型恢复偏好但不恢复上次查询或选择。
- 应用包的偏好位于用户 Application Support/FsearchDesktop；项目运行使用 `.build/client-settings`。验证模式不写用户偏好。没有账号、远程同步或默认查询日志。

## 验证（2026-10-13）

用户确认测试接缝为 SearchModel/LocalPreferences 的重启行为及原生关窗重开。执行：

```sh
bash scripts/dev.sh test --filter LocalPreferencesTests
bash scripts/dev.sh check
bash scripts/dev.sh test
bash scripts/dev.sh ui-smoke
```

- LocalPreferencesTests：3 项通过，包括检查器变化后立即创建新模型、其他偏好恢复、查询/选择/范围/筛选不恢复及偏好成品中无私密标记。不固定 JSON 字段布局。
- 完整 XCTest：服务 49 项、应用 18 项，共 67 项，0 失败；Rust check 和 Swift 构建通过。
- 原生样本窗口：`performClose` 后不可见，重新打开后模型输入、编辑器文本及选择一致。截图 `.build/native-smoke/settings-window-reopened.png`；日志 `.build/wave3-native-smoke.log`。
- 普通沙箱启动遇到 LaunchServices/XPC 错误；结束本次卡住的进程后，在获准的沙箱外执行同一入口，退出状态为 0。

本次重启回归通过新建应用模型验证；没有将其写成实际退出并重新启动已安装 DMG 的证据。实际 Engine 关窗继续索引的既有证据见 [T07](T07.md)，本次原生样本模式不替代真实 Engine 或安装验收。
