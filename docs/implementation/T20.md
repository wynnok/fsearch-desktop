# T20：主动诊断导出

对应 [GitHub #34](https://github.com/wynnok/fsearch-desktop/issues/34)，父规格 [SPEC-08](../specs/08-data-updates.md)。本次补足 `93f37fb` 的诊断版本记录与成品验证。

## 实现与边界

- 用户从搜索菜单主动选择导出；保存面板先说明包含版本、架构、系统、索引状态和错误类别，不含完整路径、正文、查询历史及原始 stderr，不自动上传。
- 报告按白名单构造。上游错误及 stderr 不原样打包，初始化、查询、桥接、其他错误分别保留类别和可操作的固定说明。
- 真实服务的版本包含 `版本 / 40 位 commit`；此前过滤器将其写成 unknown。本次仅允许三段数字版本和 ASCII 十六进制 commit，保留合法 pin；任意路径、正文或附加信息仍写成 unknown。回归先失败再通过。
- 保存失败继续抛出给导出入口，由入口显示目标位置/权限检查说明，不报告成功。
