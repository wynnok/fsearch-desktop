# 开发验证版使用指南

当前有原生客户端、两架构开发 DMG 和受控样本验收入口，但尚未通过完整 alpha/公众发行门禁。**当前开发包默认是样本验证模式，只搜索内置受控样本，不搜索你的个人磁盘。** 窗口顶部的模式和覆盖说明是判断搜索来源的依据；“所有已覆盖内置位置”不会把样本模式变为全盘搜索。

开发包为未公证、ad-hoc 签名产物。安装、Gatekeeper、Intel 与 macOS 13 实机验收仍有缺口；不要关闭系统安全保护来代替验证。下载链路和安装门禁见 [T22](../implementation/T22.md)，本轮旅程报告见 [Wave 4](../implementation/Wave4.md)。

## 搜索、范围与筛选

主窗口的“文件名搜索”只匹配名称。输入名称或名称片段，点击“查询文件名”或按 Return（⌘Return 也可）。Shift+Return 可输入文件名本身包含的换行；粘贴的换行也保留，不表示切换为正文搜索。⌘F 聚焦输入；⌘R 刷新。包含模式默认不区分大小写，标点、冒号、引号和换行按名称数据处理；模糊、前缀、后缀、完整名称可从名称匹配方式切换。不是高级查询语法或正文检索。

空输入且没有有效范围/属性条件时不会列出全部文件；仅有有效筛选或限定范围时可执行查询。没有匹配、查询失败、无效筛选和部分结果有独立状态。无效筛选保留条件，修正后可重试。

范围菜单提供所有已有覆盖、个人目录及选定文件夹。选文件夹只缩小已有结果，不建立索引，也不授予读取权限。样本模式选择个人目录不会开始扫描个人目录。隐藏项默认可见，可用“显示隐藏项”切换。

展开“属性筛选”，按文件/目录、扩展名、索引大小或修改时间组合过滤。扩展名用逗号分隔；大小用字节，大小与时间包含两端边界；可逐项清除或清除所有属性条件。最小值大于最大值等错误会提示修正。

点击名称、大小、修改时间列标题切换升降序。完整查询的排序作用于整个快照，随后分页；“载入更多”继续同一快照。查询/排序/刷新会产生新快照，正在处理时旧行仅供选择，不能视为新查询结果；部分结果只保证已载入排序，总数未知。显式排序优先于模式默认值，偏好可跨启动保留。

## 权限、覆盖与索引成本

名称索引就绪不等于所有文件已经收录，也不等于正文处理完成。权限引导可跳过，可打开系统设置入口或重新检查；应用不自动修改系统权限。样本模式不能证明 TCC/完全磁盘访问有效，也不代表真实 Engine 扫描你的磁盘。

真实 Engine 的专用验证保留上游默认后台文本内容索引机制，资源成本见 [T09](../implementation/T09.md)。v0.1 窗口提供名称搜索，后台索引正文不代表已提供内容搜索；样本模式本身不启动真实 Engine。当前没有对个人磁盘的覆盖或性能承诺。

外接/网络卷不在首版默认内置磁盘覆盖承诺内。iCloud 尚未本地下载的正文可能不可用，应用不会为后台搜索主动批量下载。PDF、Office、OCR、压缩包正文不属于当前名称搜索能力；系统预览支持某种格式也不能说明正文可搜。

## 结果、检查器与文件动作

点击或上下键选择结果；可多选。检查器显示完整路径、索引大小以及当前读取的类型、实际大小和时间。**索引大小可能因精度或文件变化与实际大小不同**，筛选和排序使用索引记录。实际大小也不是磁盘占用；目录/应用包不递归汇总，多选不虚构汇总大小。

回车或双击用系统打开单个所选对象。右键可在 Finder 显示所选项目或复制完整路径；底部路径导航可打开任一级祖先文件夹，折叠的祖先仍可从菜单访问。“打开父文件夹”和“在 Finder 显示文件本身”是不同动作。

空格开启 Quick Look，切换选择更新预览，Escape 关闭。预览受系统支持格式和可访问性限制；文件删除、链接目标缺失或没有读取权限时会说明失败。云端占位内容需先在 Finder 下载。多选时提示先选择单个项目执行动作；本应用不提供移动、删除或重命名功能。

## 关窗、退出与本地数据

红色按钮关闭主窗口；菜单“重新打开搜索窗口”或 ⌘0 可恢复当前进程的输入与选择。⌘Q 退出应用。默认不安装登录启动任务。真实 Engine 在关窗时继续运行的证据来自专用验证，默认样本模式不声称有真实后台索引。

必要偏好与查询历史分开：保存名称模式、显式排序、隐藏项、检查器显示及跳过权限引导状态，默认不持久保存查询、选择、范围或属性筛选。没有账号或远程同步。

应用包运行时偏好文件位于 `~/Library/Application Support/FsearchDesktop/preferences.json`；项目开发运行使用 `.build/client-settings`，验证模式不写用户偏好。`.build` 下的验证索引、缓存和样本都是开发资源。真实 Engine 的索引目录由独立服务入口指定，不与 CLI 共用；当前默认样本应用没有已交付的个人磁盘索引位置。

退出再移除应用包不会自动清除独立索引、CLI 数据或偏好。需要清理时先核实目录归属并保留备份；不要把 CLI 索引、用户文件或仍使用的索引当作临时验证资源删除。更换引擎版本的索引兼容性须另做验证，不承诺旧索引可无损复用。

## 诊断与手动更新

从“搜索 → 导出诊断报告…”主动导出。保存面板会说明报告内容：应用/引擎版本、架构、系统、索引状态和错误类别。完整路径、正文、查询历史、原始 stderr 不进入默认报告，不自动上传；保存失败会提示检查目标权限。

“关于 Fsearch Desktop…”和“检查更新…”打开版本/更新窗口。检查的是项目正式 Release；无 Release、没有新版或网络失败均有说明，失败不影响搜索。下载入口是 [项目 Releases](https://github.com/wynnok/fsearch-desktop/releases)，由你自行下载和安装；不会自动替换应用或已加载引擎。打开入口不表示当前已存在正式包。

## 文本内容入口（受控真实 Engine）

主窗口右上方及搜索菜单的“文本内容搜索…”打开独立正文输入框，提供普通文本或正则查询，按文件显示匹配行，并可打开、Quick Look、在 Finder 显示或复制路径。查询可选择智能、区分或不区分大小写，并复用名称窗口的范围与属性筛选。默认名称样本模式仍不支持正文，入口禁用并显示模式限制；明确启动的受控真实 Engine 才可使用，入口与验证方式见 [T30](../implementation/T30.md)、[T31](../implementation/T31.md)。

智能大小写只有在模式不含大写字母时才忽略大小写；显式选择会覆盖该行为。普通文本模式不解释正则元字符；非法正则会保留输入并提示修正。匹配行直接高亮中文、emoji、组合字符和安全截断后的 UTF-8 范围。

最多 100 个文件，每文件最多 5 条匹配行，片段约 400 UTF-8 字节，250ms 预算。文件数与正文匹配数分开；`continue` 使用上游内容 cursor，不会混用名称分页 offset。存在 cursor 或上游未完成时会显示为部分结果，候选完成不自动表示全部匹配均已显示。PDF/Office/OCR、压缩包及云端未下载正文不作为支持能力；Quick Look 能预览文件不代表正文可检索。片段不默认进入诊断或历史。详细边界见 [T33](../implementation/T33.md)。
