# 原生交互方案

状态：主要交互行为已由用户确认，布局和控件实现仍待验证。基于用户给出的 Scherlokk 区域参考重新组织信息，不复制其蓝色工具条、图标布局或大面积多行表单。

原生系统背景、SF Symbols、系统强调色、深浅模式和窗口交通灯；视觉强调用于当前选择和活动条件。先保证密集列表的可读性，不增加卡片、网格和树状视图。

## 搜索配置区

普通模式：名称输入、匹配方式、范围选择和可展开筛选。名称默认不区分大小写的包含匹配；模糊匹配可容错，通过明确选项启用，不让用户把不连续的结果误解为错误。

主窗口明确标注“文件名搜索”，不把名称查询与正文查询混成一个含义不明的输入框。名称可以包含换行；Return 提交查询，Shift+Return 插入换行，粘贴的换行作为文件名字符保留。

空输入且没有有效筛选条件时展示搜索提示，不触发全量结果查询和排序。用户设置类型、大小、时间等筛选后，可只按条件查询；默认范围和隐藏项开关不单独触发全量查询。

范围默认内置磁盘所有已覆盖位置，提供个人目录和原生文件夹选择器。选择位置只改变查询范围；当前引擎不能收录的卷要显示原因，不能给出“索引完成”的假反馈。

首次启动解释完全磁盘访问权限会增加哪些覆盖，允许跳过并搜索已有覆盖；权限受限状态持续可见，用户以后可授权并重新检查。不把拒绝授权当成真实无结果，也不要求先授权才能打开应用。

筛选项使用“文件类型”“大小”“修改时间”等普通语言，支持清除单项和全部条件。高级查询语法仅在明确高级模式下开放，错误保留输入并指出相关条件。普通文件名中的 `size:` 等字样不能自动变成过滤器。

文本内容搜索使用独立入口和独立输入框，明确标注为文件正文搜索，提供普通文本 / 正则及大小写方式；不承诺预览得到的 PDF 文本就能被搜索。样本名称模式禁用正文入口并说明原因。内容模式分页使用内容游标，不能复用名称分页 offset。

## 搜索结果区

列表先提供名称、所在文件夹、大小、修改时间。时间默认本地格式，完整时间可在检查器查看。文件夹大小显示“—”，不能当成整个文件夹递归占用；日期/大小未知也显示“—”。

点击列头按该字段全局排序，再次点击反向。保持当前选中文件；同值使用路径作为稳定次序。包含搜索默认名称自然升序（例如 `文件2` 在 `文件10` 前），模糊搜索默认关联性排序；用户显式选择其他排序后保留选择。需要更多结果时分页载入，精确总数只有在引擎/适配层明确返回完整匹配集合后才能显示。

默认显示所有匹配的已索引结果，包括隐藏项；提供清楚的隐藏项显示开关，不自动额外排除系统目录。用户通过范围和筛选缩小结果，可见性设置不意味着删去底层索引条目。

全局排序异步执行，完成前明确显示“正在排序”，临时顺序和数量不标为最终结果；用户仍可修改查询，过期排序结果丢弃。首版大小列和大小排序沿用 Fsearch 索引精度；检查器读实际大小，对大文件的精度差异提供说明。

内容搜索一文件一结果，匹配行是该文件的展开信息，避免同一文件多行导致文件总数混淆。若预算耗尽，显示“已找到 N 个文件，仍可能有更多”并提供继续，而不是“共 N 个”。

搜索条件改变后保留列表到新首屏就绪，查询状态可见；过期响应丢弃。文件变更自动合并刷新，结果按当前查询与排序重新呈现，以路径保持所选文件，并尽量保持滚动位置。文件消失时解释原因并更新选择，不把键盘选择跳到无关文件。

## 文件信息区和路径导航

单选立即显示已知名称/路径/大小/修改时间，扩展属性和预览异步加载，晚返回要与当前选择校验。多选暂显示数量和共有位置，不拼装一个虚构的文件信息。

P0 展示文件图标、类型、大小、创建和修改时间；P1 再提供所有者、权限、访问时间等更多属性。读取失败显示未知/不可访问，不显示零值或由修改时间猜创建时间。应用包作为可打开的包呈现；符号链接明确标识，不自动跟随遍历。

底部路径从卷/根位置到父文件夹再到文件。点击任一文件夹通过 NSWorkspace 打开该文件夹的 Finder 窗口；“在 Finder 显示”则选中结果本身，两种动作区分。路径太长时折叠中间祖先，用原生菜单提供完整层级，最深父文件夹和文件名尽量保留。失效路径提示文件已移动或位置不可用，并允许复制原路径。

Quick Look 使用系统预览；它可能支持更多文档类型，这不扩展 Fsearch 的搜索范围。预览 iCloud 文件可能需要用户主动下载，应让系统处理用户明确触发的打开行为，不借此自动批量下载。

## 窗口和应用生命周期

点击红色关闭按钮只关闭窗口，应用和索引仍运行；重新打开应用恢复窗口。通过 ⌘Q 或菜单“退出”完全结束应用及其自身引擎运行。开机启动由用户主动启用，默认关闭；不自动安装登录任务。客户端默认使用独立索引目录，退出不能终止不属于本应用的外部 CLI 进程。

## 更新和本地数据

首版菜单提供检查更新入口和下载链接，用户手动下载安装包；自动下载安装以后单独评估。菜单与 About 展示当前客户端及引擎版本，便于对应发布说明。

索引和设置保存于本机，默认不持久保存搜索历史；当前窗口中的输入与选择可在应用运行期间保留，不等同于跨启动历史。用户主动导出诊断时默认去除完整路径和文件内容，导出前说明保留的信息。保存查询作为后续明确功能。

## 必须设计的状态

| 状态 | 用户可见行为 |
| --- | --- |
| 空查询 | 没有有效筛选条件时显示搜索提示；有用户设置的筛选时可仅按条件查询 |
| 首次索引 | 展示收录数量或不确定进度；不制造百分比/预计完成时间 |
| 名称就绪、内容构建中 | 允许文件名搜索，分别解释内容搜索状态 |
| 权限受限 | 可继续搜索；清楚说明覆盖受限并提供授权说明 |
| 无匹配 | 展示当前条件及清除筛选操作，不与引擎失败混用 |
| 查询错误 | 保留输入，指出引擎返回的错误 |
| 引擎失败 | 重试入口和可导出的诊断信息；默认不记录完整路径或内容 |
| 文件已消失/卷离线 | 清楚说明所选文件不可用，保留路径复制能力 |
| 内容搜索未完成 | 已有结果 + 继续搜索，不显示精确总数 |
