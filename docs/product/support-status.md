# 支持状态与已知限制

当前客户端版本为 **0.2.0**，GitHub Releases 提供 **v0.2.0-unsigned** 未签名、未公证预发布包，包含独立的 `arm64`、`x86_64` 和 `universal` DMG。普通启动使用真实磁盘引擎，并启用文件名与文本内容搜索；正式签名版尚未发布，也未达到公众稳定版门禁。操作见[使用指南](user-guide.md)，本版变化见[发布说明](../releases/v0.2.0-unsigned.md)，验收缺口见 [T27 报告](../implementation/T27.md)。

## 支持矩阵

| 环境 | 构建/链接 | 实际安装与运行 | 当前结论 |
| --- | --- | --- | --- |
| Apple Silicon / 本机 macOS 27.0.1 | 通过，arm64 原生切片 | 本机 DMG 临时安装、受控样本旅程和退出通过 | 可用于本机开发验证，不能外推个人磁盘覆盖 |
| Intel Mac / x86_64 | Universal 包含切片，基线构建/链接通过 | 无 Intel 实机证据 | 未验证，不能承诺运行支持 |
| macOS 13 | 部署目标和构建产物最低系统核对通过 | 无 macOS 13 实机证据 | 目标版本，尚非已验证支持承诺 |
| 干净账号/设备首次安装 | 有本机临时 Applications 安装路径 | 无干净环境完整权限/Gatekeeper 旅程 | 未验证 |

两种芯片和 macOS 13+ 是产品支持目标。编译切片、设置 deployment target 或 Rosetta 运行均不能替代对应设备/系统证据。

## 已知限制

- **默认桌面模式**：当前源码构建的包普通启动使用真实磁盘引擎，独立索引保存在 `~/Library/Application Support/FsearchDesktop/index`，不共用 CLI 数据。显式样本和受控验证入口继续供开发使用。
- **权限与覆盖**：真实 TCC 授权前后、撤销/重启、完全磁盘访问和受保护位置结果仍未验证。名称就绪不等于覆盖完整；样本模式不能用来判断系统权限是否生效。
- **结果与大小**：完整查询快照才保证全局排序；部分结果只保证已载入排序且总数未知。大小筛选/排序采用索引记录，可能有精度差异，检查器实际大小也不是磁盘占用；目录和应用包不递归汇总。
- **资源与文本边界**：真实 Engine 保留上游默认后台文本索引，受控内容入口支持上游准入的文本、大小/忽略规则和直接读取回退，不承诺穷尽未索引位置。已有受控资源报告不能代表个人 home 的初建或长期成本；PDF/Office/OCR、压缩包正文不在当前能力中。
- **位置与云端**：外接/网络卷不在首版默认覆盖承诺中；iCloud 尚未下载的正文可能不可用，不主动为搜索批量下载。Quick Look 的格式支持不是正文搜索支持。
- **文件动作**：Finder 请求目标已验证，Finder 可见选中状态仍缺人工观察；文件操作使用系统打开/预览，没有移动、删除或重命名功能。
- **数据与诊断**：默认不落盘查询历史；主动诊断成品已验证白名单与脱敏。真实退出重启偏好和 NSSavePanel 完整确认/取消/权限失败旅程仍缺人工证据，不自动清理用户索引。
- **下载、更新与发行**：当前提供 `v0.2.0-unsigned` 未签名、未公证 Pre-release，包含 `arm64`、`x86_64` 和 `universal` 三种安装包；没有正式签名 Release 或对应的下载/安装证据。每日上游检测及 [T24 升级 PR 兼容链路](../implementation/T24.md) 已有代码和受控回归，真实云端运行仍未验证。手动更新入口不保证已有下载包，不自动安装。缺 Developer ID/公证凭据，开发包不能标为 stable。

2026-10-14 用户确认先评审本机样本界面并提供未签名预发布包，个人磁盘入口另行推进；Intel、macOS 13 和干净账号首次安装继续保留未验证。当前无需开发者账号即可使用本地 ad-hoc 签名运行样本应用；Developer ID 签名、公证和正式发行延后，不解除 T08/T28/T29 门禁。逐票状态见 [Tickets 复核](../tickets/README.md#2026-10-14-全票复核)。

T27 的完整两芯片 alpha 验收仍未通过。按用户后续明确指示，[T29](../implementation/T29.md) 已建立受门禁约束的正式发布代码，[T30](../implementation/T30.md)/[T31](../implementation/T31.md)/[T32](../implementation/T32.md)/[T33](../implementation/T33.md) 已接入并验收受控真实 Engine 的内容查询、选项、续查与高亮；已有未签名预发布版，尚无正式签名发行，当前源码包已启用个人磁盘正文入口，但真实 TCC 授权前后与不同系统的完整验收仍需设备证据。本状态不解除前置验收条件。
