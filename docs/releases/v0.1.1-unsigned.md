# v0.1.1-unsigned

这是一次**未签名、未公证**的 GitHub Pre-release，用于在当前正式签名门禁完成前分发 0.1.1 开发验证版。

## 本版内容

- 普通启动使用真实磁盘引擎，可搜索文件名和已纳入索引的文本内容。
- 文件名搜索与文本内容搜索共用筛选、路径导航、检查器和结果操作布局。
- 打开、快速查看、在 Finder 中显示和复制路径统一放在结果右键菜单；底部只保留路径、分页和窗口控制。
- 修正选中与未选中结果时，路径栏和结果总览的左对齐。

应用内版本为 `0.1.1`；本 Release tag 是 `v0.1.1-unsigned`。

## 下载哪种包

| 你的 Mac | 建议下载 |
| --- | --- |
| Apple Silicon（M1/M2/M3/M4 等） | `Fsearch-Desktop-*-arm64.dmg` |
| Intel Mac | `Fsearch-Desktop-*-x86_64.dmg` |
| 不确定，或希望在两种芯片上都使用同一个包 | `Fsearch-Desktop-*-universal.dmg` |

## 验证范围

- Universal 包完成双架构构建、安装挂载、原生运行冒烟、文件名/文本内容搜索和退出验证。
- `arm64` 和 `x86_64` 包从同一 Universal 应用进行瘦身并重新 ad-hoc 签名，已验证 DMG 哈希、二进制架构、Info.plist 和代码签名。
- Intel 实机运行、macOS 13 实机安装、真实 TCC 授权变化和干净账号首次安装仍需对应设备验证。

## 重要说明

- 本版本没有 Developer ID 签名，也没有经过 Apple 公证。
- macOS Gatekeeper 可能阻止首次启动，需要手动放行。
- 普通启动会索引可读取的个人文件；授予完全磁盘访问可增加受保护位置的覆盖。
- 文本内容搜索不解析 PDF、Office、OCR、图片或压缩包，也不会主动下载 iCloud 中缺失的正文。
- 不要为了运行来源不明的软件而关闭系统安全保护。

## 安装

1. 按上表下载对应架构的 DMG。
2. 打开 DMG，将 `FsearchDesktop.app` 拖入 Applications。
3. 如果 macOS 阻止启动，打开“系统设置” → “隐私与安全性”，找到被阻止的应用并选择“仍要打开”。
4. macOS 15 及以后通常不再支持通过右键菜单直接绕过 Gatekeeper。
5. 公司或学校管理的 Mac 可能禁止运行未公证应用。

## 文件与校验

- 三个 DMG、各自的 build manifest、第三方许可与 `SHA256SUMS` 由同一次 GitHub Actions 构建产生。
- 使用 `SHA256SUMS` 校验下载文件；验证摘要见本 Release 资产。
- 本 Release 不构成稳定版、已签名版或已公证版承诺。
