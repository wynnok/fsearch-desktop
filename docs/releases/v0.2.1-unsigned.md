# v0.2.1-unsigned

这是一次**未签名、未公证**的 GitHub Pre-release，主要改进搜索列表多选操作和主窗口布局。

## 本版内容

- 加深结果选中行的柔和蓝色，修正选中文字对比度，适配深浅外观。
- 多选支持打开、选择共同可用的打开方式、在 Finder 中显示、显示简介、Quick Look、复制文件和复制路径；重命名仍限单个项目。
- 批量永久删除统一确认，保留文件身份校验；批量操作遇到部分失败时继续处理其他项目并报告结果。
- 移除检查器标题栏的关闭按钮，仍可通过窗口工具栏或 ⌥⌘I 显隐检查器。
- 移除主窗口底栏的“载入更多”按钮及分页提示，改为滚动到底部自动续载同一查询快照；合并重复触底通知，保留文件选择。
- 收紧底栏高度，保留路径导航与文件快捷操作，为结果列表留出更多空间。

应用内版本为 `0.2.1`；本 Release tag 是 `v0.2.1-unsigned`。内置 Fsearch 引擎保持 `0.2.1`，未修改底层搜索算法。

## 下载与安装

| 你的 Mac | 建议下载 |
| --- | --- |
| Apple Silicon | `Fsearch-Desktop-*-arm64.dmg` |
| Intel Mac | `Fsearch-Desktop-*-x86_64.dmg` |
| 需要同时适用于两种芯片 | `Fsearch-Desktop-*-universal.dmg` |

使用 `SHA256SUMS` 校验下载文件，打开 DMG 后将 `FsearchDesktop.app` 拖入 Applications。本版本仅使用 ad-hoc 签名，没有 Developer ID 签名或 Apple 公证；若首次启动被阻止，可在“系统设置 → 隐私与安全性”中选择“仍要打开”。不要关闭系统安全保护。

## 验证与限制

- 本地完整 Swift 测试 116 项及原生界面冒烟通过，覆盖多选文件操作、连续触底续载、选择保留和紧凑窗口布局。
- 发布流水线执行编译、自动化测试、双架构构建，以及 Universal 包的挂载、安装副本和原生运行冒烟；通过后上传三种 DMG、校验文件、构建记录、第三方许可及验证摘要。
- Intel 实机、macOS 13 实机、真实 TCC 授权变化和干净账号首次安装仍需对应设备验证。
