# v0.2.0-unsigned

这是一次**未签名、未公证**的 GitHub Pre-release，主要更新为 FsearchDesktop 的整体界面重构。

## 本版内容

- 新增统一设计系统：以暖纸色、墨色和低饱和大地色组织界面；主要表面使用平面、哑光填充，不使用渐变、发光或投影。
- 重新设计主搜索窗口，包括品牌标记、查询栏、匹配方式、搜索范围、隐藏项开关、属性筛选入口、结果表格、状态提示和空状态。
- 重新设计检查器、权限与索引面板、属性筛选弹层、文本内容搜索、关于与更新页面。
- 为主要按钮和菜单动作补齐图标，保留既有快捷键、可访问性标识、键盘导航和原生文件操作。
- 更新 README 中的主窗口与文本内容搜索截图。

应用内版本为 `0.2.0`；本 Release tag 是 `v0.2.0-unsigned`。内置 Fsearch 引擎保持 `0.2.1`，未修改底层搜索算法。

## 下载哪种包

| 你的 Mac | 建议下载 |
| --- | --- |
| Apple Silicon（M1/M2/M3/M4 等） | `Fsearch-Desktop-*-arm64.dmg` |
| Intel Mac | `Fsearch-Desktop-*-x86_64.dmg` |
| 不确定，或希望在两种芯片上都使用同一个包 | `Fsearch-Desktop-*-universal.dmg` |

## 验证范围

- 本地通过完整 Swift 测试套件、原生 UI 冒烟旅程和真实 Engine 文本内容搜索验证。
- 发布流水线执行编译、自动化测试、双架构构建及 Universal 包的挂载、安装副本和原生运行冒烟。
- 架构独立包从同一 Universal 应用生成，检查 DMG 哈希、二进制架构、Info.plist 和 ad-hoc 代码签名。
- Intel 实机运行、macOS 13 实机安装、真实 TCC 授权变化和干净账号首次安装仍需对应设备验证。

## 安装与校验

1. 下载对应架构的 DMG，并使用 `SHA256SUMS` 校验下载文件。
2. 打开 DMG，将 `FsearchDesktop.app` 拖入 Applications。
3. 本版本仅使用 ad-hoc 签名，没有 Developer ID 签名或 Apple 公证；若首次启动被阻止，可在“系统设置 → 隐私与安全性”中选择“仍要打开”。不要关闭系统安全保护。

三个 DMG、各自的 build manifest、第三方许可与验证摘要由同一次 GitHub Actions 构建产生。本 Release 不构成稳定版、Developer ID 签名版或已公证版承诺。
