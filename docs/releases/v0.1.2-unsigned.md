# v0.1.2-unsigned

这是一次**未签名、未公证**的 GitHub Pre-release，整合搜索界面优化与新版应用图标。

## 本版内容

- 使用新版“索引聚焦”应用图标，统一 PNG 源图与多尺寸 ICNS 资源。
- 文件名搜索统一匹配方式、搜索范围及操作按钮的左右边界；“权限与索引”入口增加图标。
- 重新设计权限与索引面板：放大正文，分组展示搜索能力、权限状态和授权步骤，突出检查失败及需要重启的提示。
- 文本内容搜索统一查询、匹配方式、大小写、范围和筛选的布局与信息层级。
- 文本结果采用等高文件列表，保留文件名、路径、匹配行数与单行摘要；完整匹配在右侧独立滚动，不再由单个文件撑高列表。
- 匹配详情保留行号、Unicode 高亮和复制，使用 14pt 正文；打开已有结果时默认显示首个文件的匹配和路径。

应用内版本为 `0.1.2`；本 Release tag 是 `v0.1.2-unsigned`。内置 Fsearch 引擎保持 `0.2.1`。

## 验证范围

- 发布流水线执行编译、自动化测试、双架构构建及 Universal 包的挂载、安装副本和原生运行冒烟。
- 架构独立包从同一 Universal 应用生成，检查 DMG 哈希、二进制架构、Info.plist 和 ad-hoc 代码签名。
- 新增界面回归覆盖等高文件行、大量及超长匹配内容、Unicode 高亮、独立滚动、选择切换和预载入结果。
- Intel 实机运行、macOS 13 实机安装、真实 TCC 授权变化和干净账号首次安装仍需对应设备验证。

## 重要说明

- 本版本仅使用 ad-hoc 签名，没有 Developer ID 签名，也没有经过 Apple 公证。
- macOS Gatekeeper 可能阻止首次启动；可在“系统设置 → 隐私与安全性”中选择“仍要打开”。
- macOS 15 及以后通常不再支持通过右键菜单直接绕过 Gatekeeper；公司或学校管理的 Mac 可能禁止运行未公证应用。
- 普通启动会索引可读取的个人文件；完全磁盘访问可增加受保护位置的覆盖，授权变化后按提示重新检查并重启应用。
- 文本内容搜索不解析 PDF、Office、OCR、图片或压缩包，也不会主动下载 iCloud 中缺失的正文。
- 不要为了运行来源不明的软件而关闭系统安全保护。

## 安装与校验

1. 下载对应架构的 DMG，并使用 `SHA256SUMS` 校验下载文件。
2. 打开 DMG，将 `FsearchDesktop.app` 拖入 Applications。
3. 若首次启动被阻止，按上述系统设置入口手动放行。

三个 DMG、各自的 build manifest、第三方许可与验证摘要由同一次 GitHub Actions 构建产生。本 Release 不构成稳定版、Developer ID 签名版或已公证版承诺。
