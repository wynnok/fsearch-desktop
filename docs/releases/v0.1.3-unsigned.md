# v0.1.3-unsigned

这是一次**未签名、未公证**的 GitHub Pre-release，修复根目录搜索漏项与打开 Finder 时的应用闪退。

## 本版内容

- 修正根目录搜索范围的桥接参数，避免遗漏实时增量索引中的文件或文件夹；扩大搜索范围不再因此丢失个人目录中的匹配。
- 修复从搜索结果双击、路径栏打开 Finder 时可能触发的线程隔离断言；同时修正“打开方式”的系统回调。
- 增强 ⌘Q 退出验证：通过应用菜单触发退出，检查进程树结束、索引锁释放，并确认新进程能恢复搜索。本次核查未发现生产退出逻辑缺陷。

应用内版本为 `0.1.3`；本 Release tag 是 `v0.1.3-unsigned`。内置 Fsearch 引擎保持 `0.2.1`，未修改底层搜索算法。

## 下载哪种包

| 你的 Mac | 建议下载 |
| --- | --- |
| Apple Silicon（M1/M2/M3/M4 等） | `Fsearch-Desktop-*-arm64.dmg` |
| Intel Mac | `Fsearch-Desktop-*-x86_64.dmg` |
| 不确定，或希望在两种芯片上都使用同一个包 | `Fsearch-Desktop-*-universal.dmg` |

## 验证范围

- 本地通过 109 项 Swift 测试、2 项 Rust 测试及真实引擎原生操作验证；新增回归覆盖根目录与个人目录的基础及增量匹配、系统打开成功和失败回调、⌘Q 菜单退出及索引锁重获。
- 发布流水线执行编译、自动化测试、双架构构建及 Universal 包的挂载、安装副本和原生运行冒烟。
- 架构独立包从同一 Universal 应用生成，检查 DMG 哈希、二进制架构、Info.plist 和 ad-hoc 代码签名。
- Intel 实机运行、macOS 13 实机安装、真实 TCC 授权变化和干净账号首次安装仍需对应设备验证。退出验证通过应用菜单快捷键链路执行，不覆盖硬件键盘输入或所有运行状态。

## 安装与校验

1. 下载对应架构的 DMG，并使用 `SHA256SUMS` 校验下载文件。
2. 打开 DMG，将 `FsearchDesktop.app` 拖入 Applications。
3. 本版本仅使用 ad-hoc 签名，没有 Developer ID 签名或 Apple 公证；若首次启动被阻止，可在“系统设置 → 隐私与安全性”中选择“仍要打开”。不要关闭系统安全保护。

三个 DMG、各自的 build manifest、第三方许可与验证摘要由同一次 GitHub Actions 构建产生。本 Release 不构成稳定版、Developer ID 签名版或已公证版承诺。
