# v0.2.2-unsigned

这是一次**未签名、未公证**的 GitHub Pre-release，把内置搜索与索引引擎从 Fsearch 0.2.1 升级到 0.2.2；界面与文件操作与 `v0.2.1-unsigned` 一致。

## 本版内容

- 内置 Fsearch 引擎升级到 `0.2.2`（commit `4bc11cef48db33c45cff6578037cadb3a22bdd91`，上游正式 Release `v0.2.2`）。
- 公开库接口与名称/内容索引格式未变；本版沿用既有独立索引目录，不做运行时热替换。
- 上游降低了后台索引在高频变化目录上的 CPU 与峰值内存；本应用不复制或改写该实现。
- 缓存与构建目录（`CACHEDIR.TAG`、`node_modules`、`__pycache__`、`~/Library/Caches` 等）的变更改为静默后批量应用：通常数秒，持续变化时最坏约一分钟；其他位置仍快速更新。
- FSEvents 丢事件改为退避重放，并修复事件 journal 回退后可能漏掉改动的问题。
- 命令行新增 `fsearch version` 输出；桌面应用内不涉及该入口。

应用内版本为 `0.2.2`；本 Release tag 是 `v0.2.2-unsigned`。内置 Fsearch 引擎为 `0.2.2`（commit `4bc11cef48db33c45cff6578037cadb3a22bdd91`）。

## 下载与安装

| 你的 Mac | 建议下载 |
| --- | --- |
| Apple Silicon | `Fsearch-Desktop-*-arm64.dmg` |
| Intel Mac | `Fsearch-Desktop-*-x86_64.dmg` |
| 需要同时适用于两种芯片 | `Fsearch-Desktop-*-universal.dmg` |

使用 `SHA256SUMS` 校验下载文件，打开 DMG 后将 `FsearchDesktop.app` 拖入 Applications。本版本仅使用 ad-hoc 签名，没有 Developer ID 签名或 Apple 公证；若首次启动被阻止，可在“系统设置 → 隐私与安全性”中选择“仍要打开”。不要关闭系统安全保护。

## 验证与限制

- 本地完整 Swift 测试 117 项通过（59 项服务、58 项应用），受限真实 Engine 生命周期、原生内容旅程与界面冒烟通过。
- 发布流水线执行编译、自动化测试、双架构构建，以及 Universal 包的挂载、安装副本和原生运行冒烟；通过后上传三种 DMG、校验文件、构建记录、第三方许可及验证摘要。
- 真实用户旧索引跨版本恢复、真实 TCC 授权变化、Intel 实机、macOS 13 实机和干净账号首次安装仍需对应设备验证。
- 缓存/构建目录的刷新延迟是上游 0.2.2 的默认行为，本版不提供关闭开关。

本版本为早期测试用 Pre-release。支持状态与已知限制见[支持状态](../product/support-status.md)。
