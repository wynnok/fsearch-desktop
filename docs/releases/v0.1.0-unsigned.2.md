# v0.1.0-unsigned.2

这是一次**未签名、未公证**的 GitHub Pre-release，用于架构分发的早期验证。

本版本在 `v0.1.0-unsigned` 的基础上增加了独立的 Apple Silicon 和 Intel 安装包。应用代码与 `v0.1.0-unsigned` 一致，仅发布资产和验证方式不同。

## 下载哪种包

| 你的 Mac | 建议下载 |
| --- | --- |
| Apple Silicon（M1/M2/M3/M4 等） | `Fsearch-Desktop-*-arm64.dmg` |
| Intel Mac | `Fsearch-Desktop-*-x86_64.dmg` |
| 不确定，或希望在两种芯片上都使用同一个包 | `Fsearch-Desktop-*-universal.dmg` |

## 验证范围

- Universal 包完成完整构建、安装挂载、原生运行冒烟、搜索/文件旅程和退出验证。
- `arm64` 和 `x86_64` 包从同一 Universal 应用进行瘦身并重新 ad-hoc 签名，已验证 DMG 哈希、二进制架构、Info.plist 和代码签名。
- Intel 实机运行和 macOS 13 实机安装仍需要下载者在对应机器上验证。

## 重要说明

- 本版本没有 Developer ID 签名，也没有经过 Apple 公证。
- macOS Gatekeeper 可能阻止首次启动，需要手动放行。
- 本版本默认是样本验证模式，只搜索仓库内置样本，不索引个人磁盘。
- 不要为了运行来源不明的软件而关闭系统安全保护。

## 安装

1. 按上表下载对应架构的 DMG。
2. 打开 DMG，将应用拖入 Applications。
3. 如果 macOS 阻止启动，打开“系统设置” → “隐私与安全性”，找到被阻止的应用并选择“仍要打开”。
4. macOS 15 及以后通常不再支持通过右键菜单直接绕过 Gatekeeper。
5. 公司或学校管理的 Mac 可能禁止运行未公证应用。

不要在终端执行来路不明的脚本。终端 quarantine 处理仅适合你确认来源可信的开发测试环境：

```bash
xattr -dr com.apple.quarantine /Applications/Fsearch\ Desktop\ Development*.app
```
