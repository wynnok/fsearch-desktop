# 以持续跟进 Fsearch 上游为引擎集成约束

用户确认客户端可编写薄桥接并推动必要的上游改进，但必须能持续跟进 Fsearch 更新。引擎作为可升级的上游依赖，每个客户端发行版固定其版本以便复现；集成优先使用公开 API，避免复制索引和搜索算法或形成难以升级的长期分叉。相比长期维护自有引擎分支，这一选择可能要求等待或推动上游能力补足，但能继承上游改进。

每日检查上游正式发行版，发现更新自动生成升级 PR，并执行兼容性和双架构检查；通过后由维护者合并，版本 tag 触发客户端发行。必要的小范围临时补丁必须记录来源、测试和移除条件，升级时评估删除；功能扩展优先贡献上游。每个发行版固定对应引擎，用户通过客户端更新获得升级，当前尚未配置自动检测流程。
