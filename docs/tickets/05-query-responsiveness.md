## What to build

排序较慢时用户可以继续改关键词；新查询结果不会被晚返回的旧请求覆盖。

## Acceptance criteria

- [ ] 显示查询/排序中状态，期间输入、选择及窗口交互保持可用。
- [ ] 人为安排快慢请求，旧结果、旧计数和旧分页不能覆盖新请求。
- [ ] 临时顺序和数量不标成最终结果；失败或取消后仍可发起正常查询。
- [ ] 通过公开服务与原生窗口测量响应、主线程行为和大集合资源，而非只验证防抖代码。
