## What to build

红色按钮只关闭主窗口，重开恢复运行中的查询和选择；⌘Q 才结束客户端，开机启动默认关闭。

## Acceptance criteria

- [ ] 主窗口关闭后真实引擎持续运行，重开可恢复当前进程的输入与选择。
- [ ] 退出结束自身应用及其引擎，不结束外部 CLI；再启动独立索引正常。
- [ ] 默认不安装登录任务，菜单行为可发现。
- [ ] 用户流程验证与 M1 生命周期报告一致，不只断言某个回调返回值。
